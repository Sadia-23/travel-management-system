# Travel Management System

> **Academic Project Notice**
>
> This repository contains an undergraduate Software Engineering course
> project developed for **CSE412 -- Software Engineering** at **East
> West University**.
>
> The goal of this project was to apply software engineering
> concepts---including requirements analysis, system design,
> implementation, testing, deployment, documentation, version control,
> and teamwork---in a practical setting.
>
> While the application is fully functional and deployed, it is an
> academic project and **not intended to be a production-ready
> commercial system**. Some advanced features were intentionally left as
> future work.

------------------------------------------------------------------------

## Project Overview

The **Travel Management System (AITMS)** is a centralized web
application that simplifies travel planning by integrating hotel
booking, transportation booking, and AI-powered itinerary generation
into one platform.

The project demonstrates end-to-end software engineering practices
including UI design, backend development, database management,
deployment, and collaborative development using Git and GitHub.

------------------------------------------------------------------------

## Objectives

-   Build a centralized travel management platform.
-   Simplify hotel and transportation booking.
-   Generate AI-assisted travel itineraries.
-   Apply software engineering principles in a real project.
-   Deploy a complete full-stack application.

2.  Configure database credentials.
3.  Start Apache and MySQL in XAMPP.
4.  Launch the application locally.
